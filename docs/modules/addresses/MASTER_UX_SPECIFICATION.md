# ROVEXO Addresses — Master UX Specification

**STATUS:** APPROVED (UI/UX LOCK) · v1.0 · 2026-07-20  
**UI Spec:** `docs/modules/addresses/MASTER_UI_SPECIFICATION.md`

## Purpose

One place to manage Personal and (when verified) Business addresses with maximum two presses for important actions.

## Flows

1. **Personal only (non–Business Seller)** — open Addresses → list → Add Address → UK Lookup → Save  
2. **Verified Business Seller** — Personal | Business tabs, exclusive content per tab  
3. **Edit** — Edit → sheet (Edit Address / Set as Default / Delete Address) → Cancel  
4. **UK Lookup** — Postcode → Search Address → Select Address → Save  

## Principles

Mobile First · minimal · premium · full-width CTAs · no permanent Delete · no dual lists/buttons · UK First.
