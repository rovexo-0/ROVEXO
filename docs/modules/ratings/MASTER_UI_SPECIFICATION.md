## Profile header stack (locked order)

1. Avatar (center / left per surface)  
2. `@username`  
3. Verified Seller (purple check) — optional  
4. Badge chip (e.g. Diamond Seller) — gold/metal chip · never above avatar  
5. ★★★★★ gold `#F5C542`  
6. `4.9 (128 Reviews)`  
7. `125 Followers` · `85 Following` (tappable)  
8. Primary row: **FOLLOW** (purple) + **Message** (outline purple)  

## Follow button

- Height **48px** · Radius **14px**  
- Idle: purple fill · white `FOLLOW` · weight 700  
- Active: white fill · 2px purple border · purple `✓ FOLLOWING`  

## Reviews panel

- Large average + gold stars  
- Filters: All · Buyer · Seller  
- Row: avatar · @handle · role · relative time · stars · comment  

## Leave feedback

- Title Leave feedback · @user  
- 5 gold stars (interactive)  
- Optional comment  
- Checkboxes: matches description · fast delivery  
- Full-width purple Submit  

## Followers / Following lists

- Avatar · @handle · name  
- Trailing Follow (filled) / Following (outline)  

## Badges (visual key)

Bronze · Silver · Gold · Diamond · Platinum · Elite · Legend  
Stars = quality · Badge = experience  

## Forbidden UI

- Grey / purple / blue / red stars  
- Badge above avatar  
- Parallel Follow buttons outside this CTA system  
- Invented auto-reviews
