# ROVEXO FOLLOW · RATING · BADGE — Master UX Specification v1.0

**STATUS: REVIEW**

## UX principles

1. One tap Follow → optimistic FOLLOWING in &lt;150ms  
2. Failure → rollback button + counter · fail-closed copy  
3. Stars always gold · badge never confused with stars  
4. Reviews only after Completed order · immutable after publish  
5. 14-day dual silence → close window · **no invented reviews**  
6. Followers/Following lists feel like Profile (Full Width · Compact)  

## Follow UX

Open profile → see FOLLOW → tap → animation → FOLLOWING → counters bump → prefs created silently → optional settings later  

## Unfollow UX

Tap FOLLOWING → confirm or instant unfollow per Owner polish → counters drop · prefs removed  

## Review UX

Order Completed → Leave feedback → stars required · comment optional → Submit → immutable  

## Notification UX

New listing / price drop / feedback → grouped where possible · read/unread
